# Study Better Agency Mobile Application.
## Study Better operates as a third party connecting international Sub-saharan students to English schools in South Africa.


Below are the features you will find in the Study better Agency application. 
# Features
* Authentication:Firebase Email and Password login and Google Single Sign-On. 
* Dashboard:** Central navigation hub for Add Host, Add Student, Host Search, and Bookings.
* Firestore Persistence: Realtime cloud database storage for host families and student profiles.
* Search and Filters: Real-time search bar and area dropdown filters.
* Localisation: Multi-language support for English, French and Portuguese.

# Stack
* Kotlin 
* Firebase Auth and Firestore
